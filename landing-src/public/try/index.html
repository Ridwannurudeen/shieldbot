ShieldBot extension demo

Load the extension unpacked, connect a wallet, and send one transaction per verdict to watch ShieldBot decide; see the judge guide.

not connected chain unknown
Nothing is spent. ShieldBot decides before the wallet is asked, so declining in its overlay ends the request there. If you press Proceed Anyway, it reaches your wallet; reject it there.

1. Block recommended

Expect BLOCK RECOMMENDED: "Do not proceed with this transaction." Signals include a drainer pattern and an unlimited approval.

2. Unknown, never safe

Expect UNKNOWN, naming what could not be checked, rather than a clean result.

3. No major risks

Expect SAFE: No major risks detected.
